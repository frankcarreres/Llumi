# 📚 Llumi – Plataforma per a la prevenció de l'assetjament escolar

**Llumi** és una aplicació web dissenyada per ajudar en la detecció, seguiment i gestió de casos d’assetjament escolar dins del context educatiu. La plataforma està composta per un sistema complet amb panell de gestió per al centre, xat conversacional per a l’alumne, formularis guiats i un sistema de seguiment de denúncies.

## ✨ Funcionalitats principals

### Per a l’alumne:
- Inici de sessió personalitzat
- Test d’autoavaluació amb detecció de risc
- Possibilitat de fer denúncies guiades a través del xat
- Accés a recursos útils
- Visualització del perfil amb testos i denúncies vinculades

### Per al centre educatiu:
- Panell amb taules i gràfiques per gestionar els casos
- Seguiment de denúncies
- Estadístiques per centre i curs
- Autenticació específica per a cada institució
